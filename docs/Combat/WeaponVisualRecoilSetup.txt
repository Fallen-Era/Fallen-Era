1인칭 조준 사격 시각 반동 설정
=============================

설정 위치
- 무기 DA > Template > Visual Recoil Settings.
- Hitscan / 일반 Projectile의 실제 발사마다 적용합니다. 활/수류탄 차징 공격은 제외합니다.
- 로컬 플레이어의 3D 조준(기계식/레드닷)에만 적용합니다.
  비조준, 원격 캐릭터, 팔을 숨기는 Scope2D에는 적용하지 않습니다.

변수
- Enabled: 해당 무기의 시각 반동 사용 여부. 기본 true.
- Kick Translation: 카메라 좌표 기준 단발 최대 이동(cm).
  -X는 카메라 방향으로 당김, +Y는 오른쪽, +Z는 위쪽입니다.
  기본 (-1.5, 0, 0.1). 실제 메시 크기나 FOV를 확대하지 않습니다.
- Kick Rotation: 단발 최대 회전(도).
  Pitch는 지정 방향, Yaw/Roll은 각 값의 절댓값을 기준으로 +/- 범위 랜덤입니다.
  기본 (Pitch=0.8, Yaw=0.1, Roll=0.1).
- Pivot Offset: 카메라 기준 회전 중심(cm). 기본 (-15, 0, -5).
  총·팔을 이 지점 중심으로 회전시키며 카메라는 이동시키지 않습니다.
- Recovery Time: 시각 반동의 대략적인 복귀 시간(초). 기본 0.18.
  최대 변위 시점은 약 Recovery Time / 6, 그 뒤 점차 복귀합니다.
  이 시간에 정확히 잘리는 몽타주가 아니라 점근적으로 복귀하는 감쇠 스프링입니다.
- Max Stack: 연사 시 단발 기준 위치·회전 및 충격 속도의 누적 상한. 기본 3.

기존 Attribute와의 관계
- 위 이동·회전 값은 RecoilControl=0일 때의 기준값입니다.
- 실제 발사 충격 = 설정값 * (1 - 최종 RecoilControl Attribute).
- RecoilControl=1이면 새 시각 반동이 없습니다.
- 장착 무기 Instance, 이동, 파츠, 특성 등 기존 GAS 보정이 적용된 최종 Attribute를 읽습니다.
- 카메라 반동은 AttackData.RecoilSettings의 기존 방식 그대로입니다.
  조준 방향을 이전 값으로 자동 복귀시키지 않습니다.
- 시각 반동만 원위치로 돌아오므로 총을 재견착하는 느낌과 조준 방향 복귀는 별개입니다.

처리 순서와 주의사항
- 비용/탄약 지불 후 실제 발사 -> 기존 카메라 반동 및 로컬 시각 반동 충격 추가.
- 조준 컴포넌트의 기존 Tick에서 스프링 갱신 -> AimSocket 기본 정렬 -> 시각 반동 합성.
- 팔 FirstPersonMesh 전체와 부착된 무기/조준 파츠를 함께 이동시킵니다.
  AnimBP 본 수정이나 별도의 IK 설정은 필요하지 않습니다.
- 슬라이드/노리쇠 등 부품 움직임은 기존 WeaponMeshAttackMontage를 계속 사용합니다.
- 같은 후퇴/회전을 AnimBP에서도 추가하면 반동이 중복됩니다.
- 조준 해제 시 잔여 반동은 조준 블렌드와 함께 사라지고, 즉시 취소/무기 교체/사망 시 초기화합니다.
- 새 Tick 컴포넌트, 발사별 타이머, 트레이스, RPC 또는 복제 변수를 추가하지 않았습니다.
  판정 방향/스프레드/월드 무기 메시는 변경하지 않습니다.

튜닝 예시
- 라이플: 기본값에서 시작하고, 너무 약하면 Kick Translation.X의 절댓값을 늘립니다.
- 권총: Pitch를 늘려 총구 들림을 강조합니다. Pivot Offset도 손목/견착 느낌에 맞춰 조정합니다.
- 시야 가림이 심하면 Pitch와 Max Stack을 먼저 줄입니다.
- RecoilControl=0.7인 무기는 설정 충격의 30%가 적용된다는 점에 유의하세요.

자동화 검증
- FallenEra.Combat.Attachments.FirstPersonTransforms:
  정렬 후 반동 유지, 팔/무기 동반 이동, 카메라·월드 무기 불변, 연사 누적 제한,
  30/60/144 FPS 단발 최대값·복귀, Scope2D 제외, 무기 교체 초기화.
- FallenEra.Combat.Presentation.ManualRecoil:
  기존 카메라 반동의 수동 보정 유지 및 자동 복귀 없음.
