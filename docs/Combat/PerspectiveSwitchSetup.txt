1인칭 / 3인칭 시점 전환
========================

사용
- BP_HT_PlayerCharacter에서 V 키를 누르면 1인칭 <-> 3인칭으로 전환한다.
- /Game/Combat/Input/IA_Combat_TogglePerspective (Boolean)
- /Game/Combat/Input/IMC_Combat: V -> IA_Combat_TogglePerspective
- 캐릭터 Combat Input의 CombatTogglePerspectiveAction에 위 IA를 할당한다.
- BP의 CombatMappingContext에는 IMC_Combat을 할당한다.
- 다른 플레이어 BP는 같은 두 항목을 할당하면 된다. 기존 AbilityInputBindings에 중복으로 넣지 않는다.

계층
- Capsule
  - Mesh: 기존 3인칭 전신, 다른 플레이어에게도 표시
  - First Person Camera
    - First Person Mesh: 1인칭 팔과 해당 무기
  - First Person Legs: 기존 하체 전용 메시
  - Third Person Spring Arm
    - Third Person Camera
- 3인칭 카메라 기본 Arm Length=300cm, Socket Offset Y=50cm.
- 카메라 높이/거리/어깨 오프셋은 BP의 Third Person Spring Arm에서 조절한다.
- 카메라가 벽에 닿으면 SpringArm의 Collision Test가 거리를 줄인다.
- 이동/회전 조작은 기존과 같고, 카메라 사이 즉시 전환한다.

표시와 전투
- 1인칭에서는 소유자에게 팔/다리/1인칭 무기를 표시하고 전신/월드 무기는 숨긴다.
- 3인칭에서는 소유자에게 전신/월드 무기/파츠를 표시하고 1인칭 표현은 숨긴다.
- OnlyOwnerSee/OwnerNoSee를 사용하므로 다른 플레이어에게 보이는 월드 표현은 유지된다.
- 무기/파츠를 비동기로 장착한 뒤에도 현재 시점의 표시 규칙을 다시 적용한다.
- CombatPresentation의 카메라 조회는 현재 활성 시점을 반환한다.
- 시점 전환은 기존 ADS를 끝내고 이전 카메라 FOV와 1인칭 팔 Transform을 복원한다.
- 3인칭의 기계식/레드닷 조준은 어깨 시점 FOV 확대이며, 1인칭 팔을 3인칭 카메라까지 이동시키지 않는다.
- 기존 2D 스코프는 활성 카메라 FOV와 연결된다.
- 활의 1인칭 전용 카메라 Transform/팔 Sway를 3인칭 카메라에 적용하지 않는다.
- 전환 중 차징 자체는 취소하지 않으며 들고 있는 화살/투척물 미리보기만 현재 표현 메시로 다시 부착한다.
- 총구 이펙트와 로컬 투사체 미리보기의 소켓도 현재 표시되는 무기를 선택한다.

네트워크 / 성능
- 소유자는 즉시 전환하고 선택한 bool만 서버에 전달한다. 클라이언트 카메라 Transform은 받지 않는다.
- 서버에도 시점 선택을 반영하여 기존 서버 공격 시점 조회와 일치시킨다.
- SpringArm은 3인칭을 사용하는 서버/로컬 캐릭터에만 Tick을 켠다. 비소유 클라이언트에서는 Tick을 끈다.
- 무기 데이터 재로딩, Ability 재부여, 매 프레임 RPC 없이 상태 변경 시 표시만 갱신한다.

검증
- FallenEra.Combat.Presentation.PerspectiveSwitch: 카메라/계층/표시/조준 복원/입력 연결 자동 테스트.
- 기존 FirstPersonHierarchy, FirstPersonAttackMontage, Attachments 테스트를 함께 실행한다.
- PIE에서는 V 왕복 전환, 벽 근처 카메라, 무기 스왑, 조준/차징 중 전환을 확인한다.
- 리슨서버/클라이언트에서 각자의 화면만 전환되고 상대 전신이 계속 보이는지도 확인한다.
- 자동 테스트는 네트워크 PIE 화면의 실제 렌더링 품질을 대신하지 않는다.
